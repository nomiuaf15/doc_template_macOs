Welcome to DocsPro

DocsPro is a feature-rich, high-performance web clone of Google Docs designed with a vibrant, modern Material Design interface.

Key Features

  • Rich Text Formatting: Full control over typography, colors, line spacing, lists, alignments, and text styles.
  • Interactive Ruler: Drag markers for first-line indent, left indent, and right margin alignment.
  • Comments & Suggesting Mode: Highlight any text to add comment threads or switch to suggest mode to track edits.
  • Document Outline & Summary: Live heading navigation dynamically generated in the side panel.
  • AI Assistant (Gemini): Click the AI spark icon to draft, summarize, translate, or rewrite text instantly!
